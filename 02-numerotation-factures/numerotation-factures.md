Ce paramètre vous permet de régler votre ou vos compteur(s) de facturation si vous avez besoin de le réinitialiser pour la nouvelle année.

## Les étapes

1. **Menu "Option"** — Accédez au menu Option depuis votre espace zLawyer.
2. **"Numérotation des factures"** — Sélectionnez cette rubrique dans le menu.
3. **Cliquez sur "Modifier"** — La fenêtre "Modifier le compteur" s'ouvre.
4. **Saisissez "0" dans le champ "Dernier numéro"** — Puis cliquez sur "OK". La génération de votre compteur de facturation repartira à zéro pour cette nouvelle année.

> **Important :** Vous serez amené(e) à saisir votre mot de passe utilisateur afin que cette modification soit prise en compte.
